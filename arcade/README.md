# AE Arcade

After Effects 안에서 하는 게임 패널(CEP)입니다. 패널을 열면 게임 선택 화면이 나오고, 테트리스, 벽돌깨기, 오목, 체스, 틱택토, 2048, 지뢰찾기, 스네이크 중 하나를 골라 할 수 있어요. 오목과 체스는 패널 안에 들어 있는 AI가 상대해 줘서 인터넷이나 API 키 없이 무료로 돌아갑니다. 도킹 가능한 패널이라 작업하다 옆에 붙여 두고 할 수 있고, macOS 전용 설치 스크립트를 제공합니다.

- 게임 선택: ← → 로 고르고 Enter, 또는 1~8로 바로 시작(테트리스, 벽돌깨기, 오목, 체스, 틱택토, 2048, 지뢰찾기, 스네이크). 게임 중 일시정지하거나 끝난 뒤 **M**을 누르면 선택 화면으로 돌아와요.
- 마지막으로 한 게임이 선택된 채로 열리고, 게임마다 최고 점수가 저장됩니다.

## 설치

```bash
./arcade/install-mac.sh
```

After Effects를 다시 시작하고 **Window > Extensions > AE Arcade**를 엽니다.

스크립트는 `extension/`을 `~/Library/Application Support/Adobe/CEP/extensions/com.aemcp.arcade`에 복사하고(예전 테트리스 전용 패널 `com.aemcp.tetris`는 지움), 서명되지 않은 확장을 허용하도록 `com.adobe.CSXS.9~13`의 `PlayerDebugMode`를 1로 설정합니다. 지우려면 `./arcade/uninstall-mac.sh`.

## 테트리스 조작

| 키 | 동작 |
|---|---|
| ← → (A D) | 이동 (꾹 누르면 연속 이동) |
| ↓ (S) | 소프트 드롭 |
| Space | 하드 드롭 |
| ↑ / X (W) | 시계 방향 회전 |
| Z | 반시계 방향 회전 |
| C / Shift | 홀드 |
| P / Esc | 일시정지 |
| R | 재시작 · Enter 시작/계속 |
| M | 게임 선택 화면 |

화면은 패널 크기에 맞춰 통째로 커지고 작아집니다. 넓은 패널에서는 보드 양옆에 Hold와 Next·점수가 붙고, 좁고 긴 패널(옆에 도킹)에서는 Hold·Next가 보드 위로, 점수가 아래로 옮겨가 보드를 최대한 크게 보여 줍니다.

패널을 한 번 클릭해야 키 입력이 패널로 들어옵니다. 패널 밖을 클릭하면 자동으로 일시정지돼요. 게임 중에는 Space, 화살표 등을 패널이 가져가므로 AE의 프리뷰 재생이나 레이어 이동이 실행되지 않습니다.

## 테트리스 규칙

현대 테트리스 가이드라인을 따릅니다: 7-bag 랜덤, SRS 회전과 벽 킥, 고스트, 홀드, 다음 블록 5개, 락 딜레이(0.5초, 최대 15회 리셋), T-스핀·백투백·콤보 점수, 10줄마다 레벨 업. 최고 점수는 패널에 저장됩니다.

## 벽돌깨기

| 키 | 동작 |
|---|---|
| 마우스 / ← → (A D) | 패들 이동 |
| Space / 클릭 / ↑ | 공 발사 |
| P / Esc | 일시정지 |
| R | 재시작 · Enter 시작/계속 |
| M | 게임 선택 화면 |

패들 어디에 맞느냐에 따라 공이 튀는 각도가 바뀌어요(가운데는 거의 수직, 끝은 최대 60도). 스테이지 5개가 돌아가며 나오고 한 바퀴 돌 때마다 벽돌이 한 번씩 더 단단해지며, 스테이지가 오를수록 공이 빨라집니다. 숫자가 적힌 벽돌은 그만큼 더 맞혀야 깨지고 회색 벽돌은 3번 맞혀야 해요. 목숨은 3개로 시작합니다.

벽돌을 깨면 가끔 아이템이 떨어집니다: **W** 넓은 패들, **M** 공 3개, **S** 공 느리게(각 12초), **♥** 목숨 +1.

## 오목

15×15 판에서 다섯 개 이상 이으면 이기는 자유룰입니다(흑 금수 없음). 흑이 먼저 둡니다. 판을 클릭해서 두고, 오른쪽(또는 아래) 칸에서 난이도와 내 색을 고릅니다. **N** 새 게임 · **U** 무르기(내 수와 AI 수를 함께) · **M** 게임 선택.

- 쉬움: 괜찮아 보이는 수 중에서 골라 두고 가끔 위협을 놓쳐요.
- 보통: 줄마다 연결 모양(열린 3, 4 등)을 점수로 매겨 공격과 수비를 함께 봅니다.
- 어려움: 보통에 더해 연속 4로 몰아붙이는 필승 수순을 찾고, 상대의 필승 수순은 미리 끊어요.

## 체스

규칙을 모두 지원합니다: 캐슬링, 앙파상, 승진(퀸·룩·비숍·나이트 선택), 체크메이트, 스테일메이트, 기물 부족·50수·3회 반복 무승부. 말을 클릭하면 갈 수 있는 칸이 표시되고, 그 칸을 클릭하면 움직입니다. 기보는 표준 표기법으로 쌓여요. 단축키는 오목과 같습니다.

AI는 알파-베타 탐색과 기물·위치 평가로 둡니다. 쉬움은 1수 앞만 보고 실수가 섞이고, 보통은 3수(최대 1초), 어려움은 5수(최대 2초)까지 읽어요. 생각하는 동안 패널이 잠깐 멈출 수 있습니다.

## 틱택토

3×3 판에서 AI와 겨룹니다. 칸을 클릭하거나 숫자키 1~9(키패드 배치)로 둡니다. 쉬움은 자주 아무 데나 두고, 보통은 네 번에 세 번쯤 최선을 두며, 어려움은 절대 지지 않습니다(이기거나 비김). 판이 끝난 뒤 아무 칸이나 누르면 바로 새 판이 시작돼요. 전적이 패널에 쌓여요.

## 2048

방향키나 WASD로, 또는 판을 드래그해서 타일을 밉니다. 같은 숫자가 만나면 합쳐지고 2048을 만들면 성공이지만 계속 이어 할 수 있어요. **U**로 한 수 무르기, **N**으로 새 게임. 최고 점수가 저장됩니다.

## 지뢰찾기

초급 9×9(지뢰 10) · 중급 16×16(40) · 고급 30×16(99). 첫 클릭은 항상 빈 자리라 바로 죽지 않아요.

- **클릭** 열기 · **우클릭** 또는 **Option+클릭** 깃발 · **F**로 깃발 모드를 켜면 왼쪽 클릭만으로 깃발을 꽂아요.
- 숫자 칸을 클릭하면 주변 깃발 수가 맞을 때 나머지를 한 번에 엽니다.
- 난이도별 최고 기록(초)이 저장됩니다.

## 스네이크

방향키나 WASD로 뱀을 움직여 열매를 먹으면 길어지고 점점 빨라집니다. 열매 5개마다 금색 보너스 열매가 6초 동안 나오는데, 빨리 먹을수록 점수가 커요. 시작 화면에서 **벽 통과**를 켜면 벽에 부딪히지 않고 반대편으로 나옵니다. 방향키를 빠르게 두 번 눌러도(예: 위→왼쪽) 둘 다 반영돼요. **P/Esc** 일시정지 · **R** 재시작 · **M** 게임 선택.
