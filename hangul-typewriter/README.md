# 한글 타입라이터 (After Effects)

텍스트 레이어의 한글을 실제로 두벌식 자판을 치는 것처럼 자모 단위로 조립해 보여 주는 타이핑 효과입니다.

```
ㅇ → 아 → 안 → 안ㄴ → 안녀 → 안녕
ㄱ → 가 → 간 → 가나          (도깨비불: 받침이 다음 글자로 넘어감)
ㄱ → 고 → 과                 (겹모음은 두 타)
ㄷ → 다 → 달 → 닭            (겹받침도 두 타)
```

플러그인(.aex)이 아니라 **ScriptUI 패널 + Source Text 익스프레션**이라 AE 버전·OS를 타지 않고, 프로젝트를 다른 컴퓨터에서 열어도 패널 없이 그대로 재생됩니다.

## 설치

`HangulTypewriter.jsx`를 After Effects의 `Scripts/ScriptUI Panels` 폴더에 넣고 AE를 다시 시작하세요. 맥에서는 아래 스크립트가 해 줍니다.

```bash
./scripts/install-hangul-typewriter-mac.sh
```

그다음 **Window > HangulTypewriter.jsx**로 패널을 엽니다. 설치 없이 한 번만 쓰려면 **File > Scripts > Run Script File...**로 `HangulTypewriter.jsx`를 실행해도 됩니다.

## 사용법

1. 텍스트 레이어를 선택하고 패널에서 **선택한 텍스트 레이어에 적용**을 누릅니다.
2. 레이어 시작 지점부터 타이핑이 시작됩니다. 글은 평소처럼 텍스트 도구로 고치면 됩니다.
3. 세부 조정은 이펙트 컨트롤의 `한글 타자 ·` 항목에서 합니다.

| 컨트롤 | 설명 |
|---|---|
| 속도 (타/초) | 1초에 치는 타수. 자모 하나가 한 타 (기본 12) |
| 시작 시간 (초) | 레이어 시작 지점으로부터 지연 |
| 리듬 흔들림 (%) | 타마다 간격을 무작위로 흔들어 사람이 치는 느낌을 냄 (0이면 일정) |
| 문장부호 뒤 쉼 (초) | `. , ! ? …` 와 줄바꿈 뒤에 잠깐 멈춤 |
| 자모 조합 | 끄면 글자 단위로 한 번에 나옴 |
| 도깨비불 | 켜면 `간 → 가나`처럼 받침이 다음 글자로 넘어가는 과정까지 보여 줌 |
| 수동 진행 / 진행 (%) | 켜면 시간 대신 `진행 (%)` 키프레임으로 타이핑 위치를 직접 조절 |
| 커서 표시 / 커서 모양 | `|` `_` `▌` `▏` 중 선택. 타이핑 중엔 켜져 있고 멈추면 깜빡임 |
| 커서 깜빡임 (회/초) | 0이면 깜빡이지 않음 |
| 완료 후 커서 숨김 (초, 0=계속) | 다 친 뒤 이 시간이 지나면 커서를 숨김 |

- **키프레임으로 굽기:** 익스프레션을 Source Text 홀드 키프레임으로 바꾸고 컨트롤을 지웁니다. 렌더가 무겁거나 다른 사람에게 넘길 때 씁니다.
- **제거:** 익스프레션과 `한글 타자 ·` 컨트롤을 지웁니다.
- 모든 동작은 실행 취소(Cmd+Z) 한 번으로 되돌릴 수 있습니다.

## 팁과 한계

- 커서가 붙었다 떨어지면 글 폭이 바뀌므로 **왼쪽 정렬**을 권합니다. 가운데 정렬이면 타이핑하는 동안 글이 조금씩 옆으로 밀립니다.
- 익스프레션이 문자열을 돌려주기 때문에 레이어 전체가 첫 글자의 스타일(글꼴·색)을 따릅니다.
- 영문·숫자·기호·이모지는 한 글자가 한 타입니다.

## 개발

`src/expression.js`(익스프레션)와 `src/panel.jsx`(패널)를 고친 뒤 빌드하면 `HangulTypewriter.jsx`가 다시 만들어집니다. 결과물은 ASCII만 쓰므로 인코딩 문제 없이 ExtendScript에서 읽힙니다.

```bash
cd hangul-typewriter
npm install
npm run build
npm test
```

테스트는 익스프레션을 AE처럼 실행해 `각 → ㄱ, 가, 각` 같은 타이핑 단계와 커서, 수동 진행을 확인하고, 패널과 익스프레션이 ES3 문법인지 검사합니다.
